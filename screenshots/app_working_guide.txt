1. APP OVERVIEW (APP KI JAANKARI)
--------------------------------------------------------------------------------
* App Name: Bratify (Folder / Package: brat_generator)
* Platform: iOS (iPhone & iPad Optimized)
* Category: Photo & Video / Entertainment
* Core Concept:
  Bratify ek aesthetic viral meme maker aur multi-photo frame collage studio hai.
  Ye Charli XCX ke iconic lime-green (#8ACE00) "Brat" trend, low-res aesthetic blur,
  bold typography aur modern polaroid/multi-frame collages par based hai.
* Privacy & Storage:
  100% On-device, offline, private (koi login/signup nahi chahiye, koi data cloud
  pe nahi jata, sabhi photos aur saved drafts local SQLite database aur Photos
  library mein rehte hain).


================================================================================
2. APP START HOKE END TAK KESE WORK KARTI HAI (STEP-BY-STEP USER JOURNEY)
================================================================================

STEP 1: APP LAUNCH & SPLASH SCREEN (BOOT SEQUENCE)
--------------------------------------------------------------------------------
* User jab app icon par tap karke open karta hai:
  - Dark-themed Launch Screen display hota hai (black background matching Apple HIG).
  - Glowing lime-green Brat logo ke sath real-time "Boot Diagnostics" show hota hai:
    1. App Version & Build detect karna.
    2. iOS Device capabilities identify karna (iPhone vs iPad responsive mode).
    3. Local SQLite database (meme_designs.db) initialize karna.
    4. 500+ Aesthetic Frame Templates pre-warm karna (10 categories).
    5. 30+ Google Fonts typography engine load karna.
    6. User preferences check karna.
  - Sabhi initialization complete hote hi smooth fade transition ke sath app
    main dashboard par redirect karti hai.


STEP 2: ONBOARDING FLOW (FIRST-TIME USERS)
--------------------------------------------------------------------------------
* Pehli baar app open karne par 3 interactive onboarding cards aate hain:
  1. "Aesthetic Brat Memes" - Signature lime green viral text styling.
  2. "500+ Viral Frames & Collages" - Multi-photo polaroids, split duos & grids.
  3. "HD PhotoKit Export" - Instant save to Apple Photos & 1-tap share.
* "Get Started" tap karne par user seedha Main Studio Hub mein enter hota hai.


STEP 3: STUDIO HUB / HOME SCREEN (MAIN DASHBOARD)
--------------------------------------------------------------------------------
* Home screen par 4 main sections hote hain:
  A. Custom Builder ("Design Custom Frame"):
     - Top card par green "+" icon hota hai. Tap karte hi custom scratch editor
       khulta hai jaha user apni marzi se layout, slots aur borders customize kar sakta hai.
  B. "Start with a Layout" (Templates Carousel):
     - Quick horizontal scrollable layouts:
       - Classic Single (1 Photo slot)
       - Split Duo (H) (2 Photos horizontal split)
       - Split Duo (V) (2 Photos vertical split)
       - Polaroid Card (Classic vintage instant photo card)
       - Grid 4 Collage (4 Photo square grid)
       - Triptych (3 Photos side-by-side)
  C. 120+ Viral Quotes Engine:
     - 10 curated categories (Brat Summer, Pop Culture, Relatable, Sassy, Minimalist, etc.).
     - Kisi bhi quote par tap karne par wo quote automatically canvas text aur
       frame caption mein load hoke editor open kar deta hai.
  D. "My Recent Creations":
     - User ke pehle banaye gaye drafts ka fast horizontal carousel preview.
       Direct tap karke edit kar sakte hain.


STEP 4: DYNAMIC CANVAS EDITOR (CORE FEATURE - GENERATE SCREEN)
--------------------------------------------------------------------------------
* Ye app ka main creative workspace hai:
  A. Live Canvas Preview:
     - Real-time WYSIWYG preview jo exact HD export jaisa dikhta hai.
  B. Background Color & Palette Switching:
     - Classic Brat Lime Green (#8ACE00)
     - Studio Carbon Dark (#121212)
     - Crisp Minimalist White
     - Custom Color Picker (HSV / HEX / RGB full spectrum)
  C. Photo Slot Management:
     - Layout ke according 1 se 4 photo slots active rehte hain.
     - Slot 1, Slot 2 buttons par tap karke individual slots switch kar sakte hain.
     - Slot par tap karke Photo Gallery ya Camera se image choose kar sakte hain.
     - Slot tools: 90° Rotate, Flip Horizontal, Cover Fit, Crop/Zoom, Change Image, Remove Image.
  D. Draggable Text Overlay & Typography Engine:
     - Text layer ko canvas par ungli se kahi bhi drag aur position kiya ja sakta hai.
     - Double-tap ya Edit Pen icon par tap karke text type kiya ja sakta hai.
     - 30+ Aesthetic Google Fonts ka dropdown selector (Roboto, Outfit, Inter, etc.).
     - Text size slider, text color picker, rotation aur line-height adjustments.
  E. Frame Borders & Corners:
     - Border width slider, corner radius (sharp vs rounded vs circular), frame padding.
  F. Filter & Grain Effects:
     - Real-time photo effects: Vintage Film Grain, Black & White (Mono), Sepia, Cool Blue, Warm Sunset.
  G. Aspect Ratio Control:
     - 1:1 Square (Instagram Posts, Profile Pictures)
     - 4:5 Portrait (Instagram Feed optimum)
     - 9:16 Story (Instagram / TikTok / Snapchat Stories)
     - 3:4 Classic (Standard photo print ratio)


STEP 5: FULL-SCREEN CROP & ADJUST STUDIO (IMAGE CROP SCREEN)
--------------------------------------------------------------------------------
* Jab user canvas editor mein kisi image slot ke "Crop" button ko tap karta hai:
  - Dark-mode professional Crop Studio open hota hai.
  - Pinch-to-zoom aur smooth 2-finger pan gesture ke sath image adjust hoti hai.
  - Rule-of-thirds grid alignment guidelines dikhti hain.
  - Quick action buttons:
    - Rotate 90°
    - Mirror X (Horizontal flip)
    - Mirror Y (Vertical flip)
    - Reset (Original aspect wapas restore karne ke liye)
  - Pre-defined aspect ratio pills (1:1 Square, 4:5 Portrait, 9:16 Story, 16:9 Banner).
  - "Done" tap karte hi perfectly cropped photo wapas canvas ke selected slot mein set ho jati hai.


STEP 6: SAVING & EXPORTING (FINISH & SHARE)
--------------------------------------------------------------------------------
* Canvas Editor ke top actions:
  A. "Save Photo" (Green Button):
     - Canvas ko pixel-perfect HD resolution mein render karta hai.
     - iOS PhotoKit (Gal library) ke through direct iPhone/iPad ke Apple Photos
       (Camera Roll) mein save karta hai.
     - Saath hi project draft ko local SQLite database mein store karta hai taaki
       user baad mein bhi use re-edit kar sake.
     - Save hone par clean confirmation dialog display hota hai.
  B. "Share" Button:
     - Image render karke iOS Native Share Sheet open karta hai.
     - User directly Instagram Stories, WhatsApp, Snapchat, iMessage ya AirDrop
       par bina gallery open kiye send kar sakta hai.


STEP 7: SAVED LIBRARY & DRAFTS (SAVE SCREEN)
--------------------------------------------------------------------------------
* Bottom navigation bar ke "Library" tab par tap karne par:
  - User ke sabhi saved creations ek beautiful 2-column staggered masonry grid mein
    load hote hain.
  - Har saved item ke niche 3 action icons hote hain:
    1. Edit Icon (Pen): Is par tap karte hi pura saved project (text content,
       font choice, photo layout, coordinates) wapas dynamic canvas editor mein
       load ho jata hai taaki user nayi changes kar sake.
    2. Delete Icon (Red Bin): Tap karne par confirmation prompt ke sath database
       aur storage se design remove kar deta hai.
    3. Share Icon: Quick share sheet open karta hai.


STEP 8: SETTINGS & UTILITIES (SETTING SCREEN)
--------------------------------------------------------------------------------
* Bottom navigation bar ke "Settings" tab par tap karne par:
  - Rate App (App Store Review prompt trigger karta hai).
  - Share App (App link dosto ke sath share karne ke liye).
  - Feedback / Support (Developer ko direct email compose karta hai).
  - Privacy Policy & Terms of Use (Transparent in-app documentation).
  - Clear Cache (Temporary files aur cache saaf karne ke liye).
  - App Version & Build number footer.
